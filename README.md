# Skill Nexis Internship – Week 1

# Web Development Project

This repository contains the 2 projects which was completed as part of my Week 1 Full Stack Web Dev Internship tasks at Skill Nexis.

# 1. Personal Portfolio Website

A personal portfolio website created using HTML, CSS, and JavaScript.

Features:
- Home, About, Skills, and Contact Me sections.
- Responsive navigation bar with hamburger menu.
- Contact form with a JavaScript validation.
- Responsive layout for various screen sizes.

# 2. CircuitCentral – E-commerce Landing Page

A simple e-commerce landing page, designed for a fictional technical gadgets store.

Features:
- Navigation bar with cart counter.
- Hero section with Shop Now button.
- Product section displaying 4 tech gadgets.
- Add to Cart buttons that update the cart counter.
- Responsive product layout using CSS Grid & media queries.

# Technologies Used

- HTML5
- CSS3
- JavaScript

1. Download or clone this repository.
2. Open the `personal-portfolio` or `ecommerce-website` folder.
3. Open the respective `index.html` file in a web browser.
